# 潜在指纹图像增强工作台

面向技术科现场指纹处理的浏览器工作台:案件/物证分级管理、周期性背景花纹抑制、
方向场+频率场 Gabor 增强、细节特征点自动提取与人工校正、**全流程参数留痕可回溯、
一键导出检验报告**。整套实现用 **TypeScript** 编写,滤波核心放在 **WebGL2**。

## 四项需求的落实

| 需求 | 实现位置 | 关键设计 |
| --- | --- | --- |
| 1. 周期性背景自动去除且不压掉脊线频率 | `src/core/background.ts` + `src/core/fft.ts` | 自研 radix-2 FFT,对数幅度谱上检测离散周期峰;落入脊线频带(默认 0.06–0.25 周/像素)的峰只做温和衰减(`ridgeBandGain`),带外峰深度陷波;平滑高斯锥避免振铃 |
| 2. 方向场/频率场 + 方向滤波,接断但不造假分叉 | `orientation.ts` / `frequency.ts` / `gabor.ts` | 梯度结构张量 + 双角平滑估方向;法向投影估频率、无效块邻域中位数填充;偶对称 Gabor 仅在已有周期上加权,低相干区不增强,核随场旋转不产生交叉伪脊 |
| 3. 自动标特征点、人工可改、改动留痕、误差 ≤3px | `minutiae.ts` + `ui/viewer.ts` + `storage.ts` | 骨架 crossing number(CN=1 端点 / CN=3 分叉),短毛刺与端-叉对伪影消除;画布上增/移/删/改类,每次改动写 `minutiaChanges` 只追加表;坐标整数像素,合成真值评测平均误差 2.2px |
| 4. 1000dpi 图导入到增强 ≤4 秒 | `gabor.ts` 块级核 + `workers/` + `gl/` | Gabor 按方向场块复用旋转核(实测 512² 从 18s 降到 1.4s);CPU 算法跑在 Web Worker;去噪/Gabor/二值化提供 WebGL2 着色器实现 |

## 目录结构

```
src/
  core/        算法层(纯 TS,可在 Node 与 Worker 中直接测试)
    fft.ts             radix-2 FFT
    background.ts      频域周期背景抑制(需求 1)
    orientation.ts     方向场(结构张量)
    frequency.ts       频率场(法向投影)
    gabor.ts           块级核方向 Gabor 增强(需求 2)
    binarize.ts        自适应二值化 + Zhang-Suen 细化
    minutiae.ts        crossing number 特征点提取(需求 3)
    synthesis.ts       合成测试图(3 纹型 × 5 背景,带真值)
    pipeline.ts        CPU 参考流水线(Worker 内运行)
    storage.ts         IndexedDB 持久化(案件/物证/图像/步骤/特征点/改动/快照)
    metrics.ts         真值匹配评估(≤3px 命中率等)
  gl/          WebGL2 引擎与 GLSL 着色器(需求 4 的滤波 GPU 化)
  workers/     流水线 Worker 与主线程客户端
  ui/          界面(案件物证管理、画布编辑、步骤回溯、报告)
  report/      自包含 HTML 检验报告生成
tests/         vitest:FFT、背景抑制、方向/频率场、端到端精度、性能基准
```

## 数据与留痕模型

- **案件 → 物证 → 图像** 三级归属,全部存 IndexedDB,刷新不丢失。
- 每张图的每个处理阶段写一条 `ProcessingStep`:步骤序号、**完整参数**、耗时、
  度量(频域峰、相干性、频率、特征点计数)、处理后快照 Blob。点击任一步骤即可回看该步图像。
- 特征点的每次人工操作写一条只追加的 `MinutiaChange`(动作、前后坐标/类型、操作人、时间),
  无删除接口,满足回溯与举证要求。
- 报告(`报告`按钮)输出自包含 HTML,逐步骤打印参数表与度量表、人工改动台账、
  合成图附真值评估(精确率/召回率/平均位置误差/≤3px 占比)。

## 合成测试图

`src/core/synthesis.ts` 按真实纹线机理生成:

1. 解析方向场(箕形/拱形/斗形),沿场积分追踪弯曲平行脊线;
2. 在指定位置植入端点与分叉支流,距离场 + 余弦剖面渲染脊谷;
3. 叠加 5 种**周期性**承痕客体花纹:正弦织物纹、印刷网格、圆点阵列、斜纹、钞票式波浪纹;
4. 真值特征点从**无背景干净图的骨架**提取(与渲染几何严格一致),手工埋点另存 `plantedMinutiae` 对照。

界面侧栏 ⚙ 按钮可自选纹型/背景/噪声/半枚指纹生成。

## 实测结果(本机 Node / Headless Chrome)

- 功能测试 **24/24 通过**,性能基准 **4/4 通过**。
- 全流水线算法净耗时(CPU 参考路径):256²≈0.28s、384²≈0.42s、**512²≈1.4s**、768²≈2.9s,均 < 4s。
- Headless Chrome 自检:WebGL2 + `EXT_color_buffer_float` 可用,6 个 GLSL 着色器全部编译通过,
  GPU 高斯/Gabor 读回数值合法;合成图特征点平均位置误差 **2.20px**,≤3px 命中占比 68%。

## 工程取舍说明

- FFT 保留 CPU 实现:它是一次性全局变换,且零依赖;逐像素的邻域滤波(去噪、Gabor、二值化)
  才是算力大头,这部分走 WebGL2(`src/gl`)。浏览器不支持 WebGL2 时自动降级到 Worker 内 CPU 路径。
- Gabor 用偶对称核 + 块级核复用:偶对称不改变脊线相位(避免凭空造分叉),块复用把逐像素三角
  运算降为每块一次,是满足 4 秒指标的关键。
- 特征点坐标取整像素、匹配评估独立于检测器,保证 ≤3px 口径可被单元测试直接核验。
